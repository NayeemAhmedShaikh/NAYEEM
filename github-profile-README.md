# Hi, I'm Nayeem 👋

### Software Developer & Creator of [FastSaveMedia](https://fastsavemedia.com)

📍 Bengaluru, India

I build fast, privacy-first web tools that run right in the browser. Most of my tools process files on the user's own device, so nothing gets uploaded to a server. My work covers browser-based video and PDF processing, device diagnostics (speaker, display and touch screen tests), office calculators and developer utilities, with a focus on speed and accessibility.

### What I work on
- 🎬 **Browser media processing** with FFmpeg.wasm and Web Workers
- 🔊 **Audio tools** built on the Web Audio API
- 📄 **PDF tools** that run fully client-side
- ♿ **Accessible, fast web apps** with clean SEO and structured data
